How Supabase Validates Users:

1

Client Sends Credentials

Client sends email/password securely over TLS to Supabase GoTrue Auth service (/auth/v1/token).

2

Supabase Issues Signed JWT

GoTrue checks password hash in auth.users, creates an Access Token signed with project secret & returns a Refresh Token.

3

Session Cached Locally

The Supabase JS client persists the session in browser storage and triggers onAuthStateChange.

4

PostgreSQL Validates with RLS

Requests send Authorization: Bearer <token>. Postgres decodes the JWT and applies Row Level Security policies automatically.
